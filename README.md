# 📝 6️⃣ https-tda-photo.ru-

![Главный скриншот](screenshots/screen1.jpg)

## О проекте
Веб-портфолио с Flask и фронтендом: слайдер, сетка фото, модальные окна, кнопка “назад”.

## Технологии
- Python 3.10 / Flask
- HTML, CSS, JS
- SQLite (опционально)


## Установка и запуск

git clone https://github.com/IOXNSUN/https-tda-photo.ru-.git
cd https-tda-photo.ru-
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
