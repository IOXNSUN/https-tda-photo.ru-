# https-tda-photo.ru- 🎨

## О проекте
Профессиональное веб-портфолио с фотогалереей, построенное на Flask. Проект демонстрирует комплексный подход к разработке: от backend-логики до продвинутой конфигурации Nginx с акцентом на безопасность, производительность и пользовательский опыт.

Сайт работает в продакшене 24/7 и включает интеграцию с CPA-тестером через Flask Blueprint.

## 🚀 Ключевые возможности

### Backend (Flask)
- **Модульная структура:** основное приложение + Blueprint для CPA-тестера
- **Динамическая генерация контента:** жанры и фотографии загружаются из файловой системы
- **Умная маршрутизация:** 4 основных раздела + детальные страницы жанров
- **Мониторинг производительности:** встроенный замер времени выполнения каждого запроса
- **Комплексное логирование** всех исключений в stderr

### Frontend
- **Чистый HTML/CSS/JavaScript** без фреймворков
- **Адаптивный дизайн:** mobile-first подход с медиазапросами
- **Минималистичный интерфейс:** черная тема с акцентом на контент
- **Интерактивность:** JavaScript слайдер + двойная система лайтбокса (основная и fallback)
- **Сеточная система для портфолио** и full-screen слайдер на главной

### Инфраструктура и безопасность (Nginx)
- **Многоуровневая защита:**
  - Rate limiting: API (10/мин), CPA тестер (30/мин), заказы (10/мин)
  - HTTP Security Headers: X-Frame-Options, X-Content-Type-Options, CSP
  - SSL/TLS: только современные протоколы (TLS 1.2-1.3)
- **Оптимизация:**
  - Кэширование статики с длительным сроком жизни
  - Gzip-сжатие текстовых ресурсов
  - Поддержка современного формата WebP
  - Отделение статики от логики для масштабирования

## 🛠 Технологический стек
- **Backend:** Python 3.10 / Flask
- **Frontend:** HTML5, CSS3, JavaScript (vanilla)
- **База данных:** SQLite (опционально)
- **Веб-сервер:** Nginx (с продвинутой конфигурацией безопасности)
- **Инфраструктура:** systemd, автоматические бэкапы, мониторинг
